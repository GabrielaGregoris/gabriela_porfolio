The Dreamers Club - Artist Merch Website

I created this website to launch the record album and merchandise for The Dreamers Club, a fictional band. The visual style matches the vinyl record jacket and poster/lyric sheet I designed for the project. The site functions as a hub for fans to view the new album and merch, while the specific song names and tracklist were generated using AI software to complete the fictional narrative.

Tools Used: Visual Studio Code, GitHub, and AI (to generate music and song titles).
